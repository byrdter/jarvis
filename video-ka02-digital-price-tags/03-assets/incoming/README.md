# Incoming Footage

Place untouched source downloads here before production ingest:

- `storyblocks/` — Storyblocks originals
- `storyblocks/_rights/` — license, asset-page, and download-history captures
- `pexels/` — Pexels originals
- `pexels/_rights/` — license and source-page captures

Do not rename or transcode incoming originals. After review, production will create normalized working
copies, record provenance, tag useful assets in the canonical asset database, and copy selected media
into scene-local `assets/` directories.
