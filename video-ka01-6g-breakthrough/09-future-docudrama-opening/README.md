# KeyAdvances 6G — Future-Docudrama Opening Proof

This directory holds the separate 60–90 second opening experiment for the proposed evidence-anchored future-docudrama format. It does not replace or overwrite the earlier V3 HyperFrames rebuild.

Working premise: In 2034, an older woman's home detects a fall without a camera or wearable, and emergency help begins moving before a person places a call.

Truth state: `2034 · DRAMATIZED FUTURE` must be visible from the first frame. Present-day evidence and limitations enter after this opening proof.
